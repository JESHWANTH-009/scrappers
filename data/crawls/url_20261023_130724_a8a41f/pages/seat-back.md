Seat Back Display Infotainment

### Seat Back Display Infotainment

### Specification For Infotainment System, Pis, Led Destination Board For Ac Chair Car, SPEC NO. MDTS 24297

### Infotainment System Along With Pis And Led Destination Board As Per Specification.

Each set consist of LCD/LED 78 or 56 nos

Server controller one nos

Led Destination Boards 2 nos

MBU1 nos.

Audio Amplifier 1 nos

Speakers 4 nos

### Infotainment System Consists of

10.5” LCD/LED Touch HMI screen

Server

Controller for infotainment on demand i.e Pre Recorded Media

Passenger information System to be displayed on each screen

GPS based LED destination board

### FEATURES

- **Server Controller For Infotainment On Demand :**

  Each passenger be provided with pre recoded media contents in the form of movies, music and documents through a server controller.
- **Public Announcement System :**

  The system should have feature for audio/video announcement which shall be broadcasted from a centralized location. The feed from public announcement should override the contents being played on each screen.
- **Passenger Information System (PIS) :**

  The information system should have provision for displaying of passenger information on a separate channel. The passenger information system shall be GPS based mapping of identified routes is to be carried out by the supplier, where the coaches shall be running.
- **Led Based Destination Board :**

  Each coach is to be provided with LED destination boards to RDSO specification no: RDSO/2013/CG-05.
