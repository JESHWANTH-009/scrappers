### Research On The Financial Planning

[Wifi - Router](#collapseOne)

Wi-Fi routers is used to access content server with passenger gadgets. One wireless access point installed for one distributed server for providing sufficient bandwidth for all the passengers.

[Ethernet Switch](#collapseTwo)

Ethernet Switch is a industrial grade Ethernet switch and it is used as bridge between Content server and distributed servers. One switch is required for each coach.

[Server](#collapseTwo)

Server is used to support the passenger devices (max. 60 devices per server). Server is connected one end to Ethernet switch and other end with Wi-Fi router to connect passengers personal gadgets. Two distributed servers are required for each double decker coach or more than 60 passengers in coach.

### Public Addressing and Passenger Information System(PA & PIS)

PAS is used to address passengers by railway attender in case of Emergency/critical conditions.

It facilities superintendant/ responsible on duty person for manual announcement of important message to passengers.

PIS is an important aspect of passenger amenity. It provides information about train location, next halting station and late running status of train will help in enhancing passenger comfort especially during night hours.

### Research On The Financial Planning

[Master Board Unit (MBU)](#collapseOne)

MBU has USB port, 4x4 keypad and LCD display as user interface for changing route number and carrying out other user functions.

MBU incorporated with a digital audio announcement unit having a Digital Signal Processor (DSP) and solid state memory. The Audio Announcement Unit (AAU) shall be capable of generating voice messages based on voice segments stored in its memory in a compressed data.

[LCD Panel](#collapseTwo)

LCD Panels are used to display PIS information. It is connected to MBU with VGA interface. There are 7 LCD displays with different sizes & connected in daisy chain manner in each coach at various locations.

[GSM Modem](#collapseTwo)

GSM modem is a interface between MBU and remote server for route selection, monitoring, configurations etc.

[Audio Amplifier Unit (AAU)](#collapseTwo)

The AAU capable to drive four no. of speakers of 6 watt R.M.S. (upgradeable to 8 speakers) in a coach.
